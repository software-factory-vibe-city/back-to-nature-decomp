## Strategy

Cherry-picking sequentially will conflict on `functions.h` every time. Instead:

1. **Extract only `src/` files** from each commit (no conflicts — each is unique)
2. **Extract `globals_override.h` changes** from `a579e17`
3. **Regenerate `functions.h`** via `npx tsx tools/contextExport.ts --all` after all src files are in place
4. **Rebuild and verify**: `make clean` → `make split` → `make check`
5. **Commit once** with all 7 functions

## Recommendations for future fixes (do NOT implement in this plan)

These are the root causes that led to 7 commits being lost:

1. **Merge conflict handling is destructive.** `processFunctions()` discards the worktree on merge conflict (`wt.cleanup(wtInfo, true)`). It should instead leave the worktree intact so the resume feature can pick it up on the next run. The fix: on merge conflict, log a warning but don't call `cleanup(wtInfo, true)`.

2. **All worktrees branch from the same HEAD.** When processing multiple functions sequentially, each worktree branches from the original HEAD. After the first merge succeeds, HEAD advances — but subsequent worktrees are still based on the old HEAD, guaranteeing conflicts on shared files like `functions.h`. The fix: after each successful merge, rebase (or recreate) remaining worktrees onto the new HEAD. Or: don't commit `functions.h` per-function — only regenerate it once at the end after all src files are merged.

3. **The escalation check fires between retries, not at the actual turn threshold.** The `setModel()` call is in the retry `while` loop, but turns accumulate inside `session.prompt()`. The fix: set a `escalationPending` flag in the `turn_end` subscription handler, then check it before the next `prompt()` call AND use `session.steer()` to interrupt the current prompt so the model stops burning weak-model tokens.

4. **No persistent log of what was attempted.** When a worktree is nuked, all evidence of the attempt vanishes. Consider writing a `build/pipeline/{funcName}/attempt.log` with the commit SHA, match percentage reached, and failure reason before cleanup.
