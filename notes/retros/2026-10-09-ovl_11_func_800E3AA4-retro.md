## The last residual

The autoloop (deepseek-v4-1-flash) reached 87/87 in under two minutes. One
difference remained in block 3: DrawSync's `move a0,zero`.
- **Target:** directly after the three `lbu` loads.
- **Candidate:** four slots later, after `addiu v0,v0,0x134`.

The second scheduling pass keeps the first pass's order here, so sched1 decides
it. sched1 (`gcc/sched.c`) schedules bottom-up, and every instruction in this
block has priority 1. The `.sched` dump's ready lists show how each slot was
filled:
- **The stores.** They beat the move on memory-unit hazard.
- **`T-25: 85 73, now 85 73`.** Once the second buffer's stores were placed,
  the move (uid 85) tied with the `addiu` (uid 73). The move won on original
  order (`rank_for_schedule`), so it was placed directly below the `addiu`.

The `addiu` was `env++`. That writes `env` a second time, so `birthing_insn_p`
refuses it and `adjust_priority` does not raise it to the top priority. With a
separate pointer, `env2 = env + 1`, the `addiu` sets a register assigned exactly
once and gets that raise. It wins T-25. The move then loses every contest until
only the loads remain, which puts it after the `lbu` loads, as in the target.
That was the first experiment, and it matched.

## Why the session missed it

- **It applied the lever to the wrong instruction.**
  - `psx_scheduler_trace` named the lever: a pointer walked with `++` is
    unpromoted, and a single-assignment local buys promotion.
  - The session tried to promote the move itself, through a single-assignment
    variable for DrawSync's argument. That folds back to the constant 0.
  - Promotion sinks the promoted instruction, so to make the move rise, its
    competitor has to be promoted.
- **It ruled out the fix from the instruction's shape.** It reasoned that
  `addiu v0,v0,0x134` "is exactly `env++`" and never measured a second
  pointer. A second pointer emits the same `addiu`.

The rest of the session went to `psx_search_residual_source_space`, whose
grammar cannot split `env++` into a new variable. That tool is now disabled.

**Transfer:**
- When one instruction sits in the wrong place in a block, follow it through
  the scheduler's ready lists to the step that placed it.
- To make it rise, make the instruction it beat there outrank it.
- `p++` and `q = p + 1` emit the same add, but only the fresh pointer can be
  promoted.
